### 📖 项目简介

**text2sign** 是一个基于纯前端（Vanilla JS）构建的轻量级 Web 应用。通过输入你的名字，它能无缝对接**火山引擎 (Volcengine) 的 SeedDream 大模型**，为你生成极具艺术感和个人风格的手写签名图片。

无需安装任何依赖，无需复杂的构建工具，开箱即用，只需一个浏览器！

### 🚀 核心特性

- **⌨️ 极简输入**：直接通过键盘输入需要生成签名的名字，方便快捷。
- **🎨 大模型赋能**：内置对接火山引擎 `seeddream-latest` 模型，生成高质量、白底黑字的流畅手写体。
- **💾 一键保存**：生成的签名支持一键下载至本地，方便用于电子文档、名片等场景。
- **⚡ 零依赖运行**：纯原生 HTML/CSS/JS 实现，无需 Node.js 环境，双击 `index.html` 即可运行。

### 🛠️ 使用方法

1. **克隆项目到本地**
   ```bash
   git clone https://github.com/YuhaoYeSteve/text2sign.git
   ```
2. **运行项目**
   - 直接双击打开根目录下的 `index.html`，或者使用 VS Code 的 Live Server 插件打开以获得更好的体验。
3. **配置密钥**
   - 在页面中输入您的 [火山引擎 API 密钥](https://console.volcengine.com/)。
4. **生成与保存**
   - 输入你的名字，点击**“生成美化签名”**。
   - 等待生成完成后，点击**“保存美化签名”**即可下载图片。

<h2 id="english-documentation">🇬🇧 English Documentation</h2>

### 📖 Introduction

**text2sign** is a lightweight, Vanilla JS web application. By simply typing your name, it seamlessly integrates with the **Volcengine SeedDream Large Model** to generate an artistic, highly personalized handwritten signature image.

No dependencies, no build tools required. It works out-of-the-box right in your browser!

### 🚀 Features

- **⌨️ Simple Input**: Easily type your name to generate a signature.
- **🎨 AI-Powered**: Integrates with Volcengine's `seeddream-latest` model to generate high-quality, fluent handwritten styles with a white background and black text.
- **💾 One-Click Save**: Download your generated signature instantly for use in digital documents, business cards, etc.
- **⚡ Zero Dependencies**: Built with pure HTML/CSS/JS. No Node.js required. Just open `index.html` and you're good to go.

### 🛠️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/YuhaoYeSteve/text2sign.git
   ```
2. **Run the app**
   - Simply double-click `index.html` in the root directory, or use the VS Code Live Server extension for a better experience.
3. **Configure API Key**
   - Enter your [Volcengine API Key](https://console.volcengine.com/) in the input field on the page.
4. **Generate & Save**
   - Type your name and click **"Generate Beautiful Signature"**.
   - Once generated, click **"Save Signature"** to download the image.
